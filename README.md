# 🎬 Netflix Recommendation System

## Overview

This project develops a personalized movie recommendation system using the Netflix Prize Dataset. The objective is to learn user preferences from historical movie ratings and generate relevant recommendations that improve content discovery and user engagement.

The system compares two recommendation approaches:

* Item-Based Collaborative Filtering
* Singular Value Decomposition (SVD)

The models are evaluated using RMSE, MAE, and MAP@10, and recommendations are visualized through an interactive Streamlit dashboard.

## 📊 Dataset

**Dataset:** Netflix Prize Dataset

The project uses a computationally manageable subset of the original Netflix Prize Dataset.

### Dataset Statistics

| Metric  | Value     |
| ------- | --------- |
| Movies  | 225       |
| Users   | 283,705   |

### Features Used

* Release Year

## 🔍 Exploratory Data Analysis

The following analyses were performed:

* Rating Distribution Analysis
* User Activity Analysis
* Movie Popularity Analysis
* User–Movie Matrix Sparsity Analysis

### Key Findings

* Most ratings fall between 3 and 5 stars.
* A small group of highly active users contributes a large proportion of ratings.
* Popular movies receive significantly more interactions than less-known titles.
* The user–movie interaction matrix is highly sparse (~98.43%).

## ⚙️ Methodology

### 1. Data Preprocessing

* Data cleaning
* Missing value handling
* Dataset transformation
* Matrix preparation

### 2. Item-Based Collaborative Filtering

* Movie-to-movie similarity computation
* Recommendation generation using nearest-neighbor similarity
* Interpretable recommendation approach

### 3. Singular Value Decomposition (SVD)

* Matrix factorization technique
* Learns latent user preferences
* Handles sparse recommendation datasets effectively
* Generates personalized recommendations

## 📈 Evaluation Metrics

The recommendation models were evaluated using:

### Mandatory Metrics

* RMSE (Root Mean Squared Error)
* MAP@10 (Mean Average Precision @ 10)

### Additional Metric

* MAE (Mean Absolute Error)

---

## 🏆 Experimental Results

| Metric | Item-Based CF | SVD    |
| ------ | ------------- | ------ |
| RMSE   | 1.1421        | 0.9924 |
| MAE    | 0.8870        | 0.7775 |
| MAP@10 | 0.9372        | 0.9512 |

### Final Model Selection

**Selected Model:** Singular Value Decomposition (SVD)

### Reason

* Lowest RMSE
* Lowest MAE
* Highest MAP@10
* Better handling of sparse user–movie interactions
